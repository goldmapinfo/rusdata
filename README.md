# RusData

RusData — проект для обработки и анализа российских данных о лицензиях на недропользование.  

Для работы необходимо скачать данные о лицензиях отсюда: https://rfgf.ru/ReestrLic/
Данные скачиваются в виде файла opendata.csv

Порядок действий:
1. Скачиваем файл, помещаем его в папку проекта /dev/RusData
2. Активируем виртуальное окружение
3. Запускаем скрипт python convertrudata.py
Скрипт удаляет аннулированные лицензии, лицензии в которых вышел срок действия.
Далее он чистит ячейку где хранятся все координаты от всякого хлама. На данный момент скрипт не учитывает дырки в лицензиях и лицензии из нескольких площадей.
Дырки просто удаляются, если площадей в лицензии несколько то берется первая (но это неточно)
Затем скрипт конвертирует координаты градусы/минуты/секунды в десятичные градусы. Важно! Скорее всего конвертация происходит как WGS84, хотя я пытался сделать ГСК-2011.
Но пока не вышло.
Лицензии которые не попадают под действие текущего скрипта (там есть координаты WGS84, Пулково 42 и другое) скидываются в файл errors_opendata.csv
На выходе получается файл convert_opendata.csv
4. Конвертируем convert_opendata.csv в geojson скриптом python 2jsonconvert.py.
На выходе получаем output.geojson
5. Скриптом python remove_zero_coords.py удаляем нулевые координаты в некоторых объектах (да, такие есть и не мало)
6. output.geojson открываем QGIS и пересохраняем в формат gpkg ибо json весит почти террабайт
7. Убираем все лишнее (output.geojson) и ручками удаляем две океанских лицензии в восточном и западном полушарии, ибо там ошибки в координатах
8. Есть еще скрипт преобразования из convert_opendata.csv output.gpkg, но он работает некорректно
9. Также есть скрипт выборки лицензий по их номерам (fid) import_numbers.py. Но номера там надо вручную делать списком.
10. Есть еще скрипт разницы между двумя файлами. Но он корректно не работает и вроде в нем нужды пока нет, проще все сделать на сатйе rfgf
